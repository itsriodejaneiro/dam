# Getting around

The home page, at `/`, opens with the title and lede the deployment writes, and the texts, cards and logos under them ([The home page](./home.md)). The header is the same on every page.

![The home page of a deployment](/screens/getting-around-1.png)

## The header

![The header for a visitor](/screens/getting-around-2.png)

| Part | What it does |
|---|---|
| the mark and the title | return to the home page. The mark is the deployment's logo or flag, and the title its [name](./configure.md#the-fields), in the page's language |
| **start** | the home page |
| **maps** | [the map](./map.md) |
| **journeys** | [the journeys](./journeys.md), when the deployment shows them |
| **EN · FR …** | the language of the site. It appears when the deployment offers more than one |
| **dark / light** | the mode of the colors |
| **sign in** | [the login](./sign-in.md), for those who edit |

Your language and your mode stay in your browser for the next visit. On a narrow window, the links move into a menu behind the **☰** button.

## After you sign in

The header adds an **Admin** menu, the **log out** button and a **⋮** menu.

![The header of a signed-in person, with the Admin menu open](/screens/getting-around-3.png)

| Item of the Admin menu | Page |
|---|---|
| **home** | [The home page](./home.md) |
| **entities** | [Entities](./entities.md) |
| **connections** | [Connections](./connections.md) |
| **maps** | [Maps](./maps.md) |
| **journeys** | [Writing a journey](./writing-a-journey.md) |
| **categories** | [Categories](./categories.md) |
| **settings** | [Configure your deployment](./configure.md) |
| **accounts** | [Accounts](./accounts.md) |

On one of these pages the button names it, **Admin: journeys**, so you know where you are without opening the menu.

![The header on the Journeys page](/screens/getting-around-4.png)

The **⋮** menu opens the [design system](./design-system.md) and, for a superuser, [Setup](./install.md#start-over). On a narrow window, the Admin pages are a group inside the **☰** menu.
