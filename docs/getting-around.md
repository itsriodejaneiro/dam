# Getting around

The home page, at `/`, names the deployment and what it maps, with the texts, cards and logos the deployment writes under it ([The home page](./home.md)). The header is the same on every page.

![The home page of a deployment](/screens/getting-around-1.png)

## The header

![The header for a visitor](/screens/getting-around-2.png)

| Part | What it does |
|---|---|
| the mark and the title | return to the home page. The mark is the deployment's logo or flag |
| **start** | the home page |
| **maps** | [the map](./map.md) |
| **journeys** | [the journeys](./journeys.md), when the deployment shows them |
| **EN · FR …** | the language of the site. It appears when the deployment offers more than one |
| **dark / light** | the mode of the colors |
| **sign in** | [the login](./sign-in.md), for those who edit |

Your language and your mode stay in your browser for the next visit. On a narrow window, the links move into a menu behind the **☰** button.
